## 四、Milvus 客户端封装

### 4.1 核心功能

| 函数 | 说明 |
|---|---|
| `get_milvus_client()` | 单例模式获取 Milvus 客户端 |
| `ensure_collection()` | 自动创建/加载 collection + 索引 |
| `bulk_insert()` | 批量插入 chunks |
| `search()` | 向量检索接口 |
| `count_chunks()` | 统计 chunk 数量 |

### 4.2 Collection 结构

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | VARCHAR(64) | 主键，xxhash64 生成 |
| `dense_vec` | FLOAT_VECTOR(1024) | 稠密向量 |
| `sparse_vec` | SPARSE_FLOAT_VECTOR | 稀疏向量 |
| `content_en` | VARCHAR(8192) | 原文 |
| `content_zh` | VARCHAR(8192) | 中文摘要 |
| `user_id` | INT64 | **partition_key** |
| `paper_id` | INT64 | scalar 过滤 |
| `folder_id` | INT64 | scalar 过滤 |
| `chunk_type` | VARCHAR(16) | text/table/figure/formula |

### 4.3 索引配置

| 字段 | 索引类型 | 参数 |
|---|---|---|
| `dense_vec` | HNSW | M=16, efConstruction=200, ef=64, COSINE |
| `sparse_vec` | SPARSE_INVERTED_INDEX | IP |
| `user_id` | PARTITION_KEY | - |
