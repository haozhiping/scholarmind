|-------|------|------|

| **检索与重排** | 构造 Milvus 过滤表达式，进行 `dense + sparse` 混合检索，使用 RRF 算法合并，调用 Reranker 进行 Top-N 重排 | ✅ |

```
Query → QueryOptimizer → HybridRetriever → AdaptiveFilter → Results
         ↓                    ↓                   ↓
   改写/翻译/HyDE      Dense+Sparse+RRF    Corrective RAG + Cache
```

## 四、API接口设计

### 4.1 检索接口

**路径**: `POST /api/retrieval/search`

| 参数 | 类型 | 说明 |
|------|------|------|
| `query` | str | 用户查询 |
| `paper_id` | int (可选) | 论文ID限定 |
| `folder_id` | int (可选) | 文件夹ID限定 |
| `top_k` | int (可选) | 返回数量，默认20 |
| `enable_cache` | bool (可选) | 是否启用缓存 |

**响应结构**:
```json
{
  "query": "原始查询",
  "rewritten_query": "改写后的查询",
  "results": [...],
  "retrieval_time": 0.5,
  "cache_hit": false,
  "quality_score": 0.85,
  "quality_action": "accept",
  "quality_reason": "检索结果相关"
}
```

### 4.2 带重试接口

**路径**: `POST /api/retrieval/search-with-retry`

自动处理 Corrective RAG 触发的重检索
